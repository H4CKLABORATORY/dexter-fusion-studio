# Camino hacia un editor profesional

- v0.1: motor propio FFmpeg, recortes por silencios, SRT, memes, perfiles, Concat API y FilmCraft/EffectCraft MCP config. Construido y probado localmente.
- v0.2: timeline editable (tabla, dividir, ajustar, zoom), fotogramas de previsualización y selección heurística de highlights. **Construido**; no tiene waveform ni reproducción continua.
- v0.3: módulo de ASR con faster-whisper local opcional, reportes de escenas y fotogramas mediante Ollama local con consentimiento, ranking de cortes y borradores editables. **Implementado en rama de etapa 3; pendiente prueba con modelos reales y PC Windows.** La diarización y subtítulos por palabra siguen pendientes.
- v0.4: modelo multimodal local para analizar TikToks autorizados, texto, ritmos y memes.
- v0.5: Concat API para timeline de cortes y efectos, no solo envío de MP4; EffectCraft con exportaciones verificadas.
- v1.0: paquete de instalador Windows y pruebas en hardware del usuario.
